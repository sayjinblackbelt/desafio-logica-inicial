# 🧠 Desafío Inicial de Lógica

[🇧🇷 Português](README.md) | [🇺🇸 English](README.en.md) | 🇪🇸 Español

> Un recorrido práctico por los fundamentos de programación con JavaScript.

Este repositorio comenzó como uno de mis primeros proyectos en GitHub y posteriormente fue reorganizado para registrar una evolución progresiva por los principales conceptos de lógica de programación.

## 🎯 Objetivo

Practicar y consolidar los fundamentos esenciales de programación antes de avanzar hacia aplicaciones y proyectos más complejos.

## ▶️ Cómo ejecutar

### Requisito previo

- Node.js instalado.

### Ejecutar un ejercicio

Desde la carpeta del proyecto:

```bash
node 01_variaveis/01_variaveis.js
```

Otros ejemplos:

```bash
node 05_funcoes/04_desafio_calculadora.js
node 08_desafios_integradores/03_jogo_adivinhacao.js
```

El objetivo de este proyecto es preservar el historial de aprendizaje y demostrar la evolución desde los fundamentos de lógica hasta la combinación de conceptos en pequeños programas completos.
