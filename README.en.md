## ▶️ How to run

### Prerequisite

- Node.js installed.

### Run an exercise

From the project folder:

```bash
node 01_variaveis/01_variaveis.js
```

Other examples:

```bash
node 05_funcoes/04_desafio_calculadora.js
node 08_desafios_integradores/03_jogo_adivinhacao.js
```
