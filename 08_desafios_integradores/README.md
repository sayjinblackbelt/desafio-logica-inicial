# 08 — Desafios Integradores

Nesta etapa, os desafios combinam os principais conceitos estudados nos módulos anteriores.

## Projetos

### 01 — Calculadora
Pratica:
- funções;
- parâmetros;
- retorno;
- condicionais;
- `switch`.

### 02 — Sistema de notas
Pratica:
- objetos;
- arrays;
- repetição;
- funções;
- condicionais.

### 03 — Jogo de adivinhação
Pratica:
- variáveis;
- arrays;
- repetição;
- condicionais;
- controle de fluxo com `break`.

## 🎯 Objetivo

Demonstrar a aplicação conjunta dos fundamentos de JavaScript em pequenos programas completos.
